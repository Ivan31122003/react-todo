# React Todo

Учебный менеджер задач на React 19, Vite и SCSS Modules.

## Возможности

- Создание, редактирование и удаление задач.
- Отметка выполнения, поиск и фильтрация.
- Статистика и прогресс выполнения.
- Автоматическое сохранение задач в localStorage между перезагрузками страницы.

## Запуск

Требуются Node.js 20.19+ (ветка 20) или 22.12+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, указанный в терминале.

## Команды

- `npm run build` — сборка в каталог `dist`.
- `npm run preview` — просмотр готовой сборки.
- `npm run lint` — проверка кода.
